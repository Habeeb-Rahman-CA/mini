# Mini Programming Language for VS Code

Official Visual Studio Code extension for the **Mini (`minilang`)** natural-English programming language.

## Features

- **Syntax Highlighting**: Full TextMate grammar highlighting natural-English operators (`the total of`, `is greater than`, `is at least`, `divided by`), declarations (`make`, `assign`), control flow (`if`, `otherwise`, `repeat`, `while`, `for`, `end`), strings, numbers, and comments (`#`, `//`, `note:`).
- **File Icons**: Light and dark theme icons for `.mini` files.
- **Live Error Diagnostics**: Instant lexer and parser error underlines in the editor with helpful `Hint:` suggestions in the **Problems** panel.
- **Code Snippets**: Fast autocompletion for `make`, `makefn`, `assign`, `total`, `if`, `for`, `foreach`, `repeat`, and `show`.
- **Editor Run Button**: Click the play button in the top-right of any `.mini` editor to execute the file via `minilang run`.
