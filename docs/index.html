Mini Programming Language

Mini (`minilang`) is an expressive, readable programming language that uses clear natural English instead of cryptic punctuation—built from scratch in TypeScript with a dedicated Lexer, Recursive-Descent Parser, AST, Expression Evaluator, and Interpreter (zero eval()). 

make add(a, b) = a + b
assign x to the total of 10 and 5
show add(x, 2)   # Outputs: 17

Installation & CLI Usage

1. Global Installation via npm

npm install -g minilang-eng

Once installed globally, both minilang and mini commands are available in any terminal on Linux, macOS, and Windows:

# Run a .mini file
minilang run examples/hello.mini
minilang examples/hello.mini

# Start the interactive REPL
minilang repl

# Validate syntax without executing
minilang check examples/hello.mini
minilang check --json examples/hello.mini

# Evaluate inline code
minilang -e 'assign x to the total of 10 and 5; show x'

# Inspect Lexer Tokens or Parsed AST
minilang --tokens examples/hello.mini
minilang --ast examples/hello.mini

# Check version and help
minilang --version
minilang --help

2. Standalone Single-File Bundle & Native Binary

To build self-contained single-file bundles (or Node.js Single Executable Applications for environments without npm):

npm run build
npm run build:standalone
node dist/standalone/minilang.mjs run examples/hello.mini

Functions & Recursion

# Single-line expression function
make add(a, b) = a + b

# Multi-line block function with 'give' (or 'return')
make factorial(n)
  if n is at most 1
    give 1
  end
  give n * factorial(n - 1)
end

show add(10, 5)
show factorial(5)

Conditionals

if score is at least 90
  show "Grade: A"
otherwise if score is at least 80
  show "Grade: B"
otherwise
  show "Keep practicing!"
end

# Single-line form:
if x is greater than 10 then show "big" otherwise show "small"

Loops & Control

# Repeat N times
repeat 3 times
  show "Hello!"
end

# While loop
assign n to 1
while n is less than 16
  assign n to n * 2
end

# For range loop (with optional 'by' step)
for i from 1 to 5
  show i
end

# For-each loop with 'skip' (continue) and 'stop' (break)
assign items to list of 10, 20, 30, 40
for each item in items
  if item is 20 then skip
  if item is 40 then stop
  show item
end

Lists & Standard Library

assign fruits to list of "apple", "banana", "cherry"
push "date" to fruits
show length of fruits          # 4
show fruits at 0               # "apple"
show fruits at -1              # "date"
assign fruits at 1 to "berry"
show join(fruits, ", ")

Safety & Execution Limits

Mini executes all code through a custom TypeScript AST interpreter without eval() or Function(), and enforces configurable resource guards out of the box:

Guard Default Limit CLI Flag
Maximum Loop Iterations 100,000 iterations per loop --max-iterations <n>
Maximum Call Stack Depth 1,000 recursive frames --max-depth <n>
Wall-Clock Execution Timeout 5,000 ms (0 disables) --timeout <ms>
Output Flood Guard 10,000 lines Programmatic maxOutputLines

Troubleshooting & Error Reference

Error Category Common Cause How to Fix
Lexer Error Unterminated string literal or invalid symbol character. Ensure every " or ' is closed on the same line.
Syntax Error Missing end on a block, missing to in assign, or missing and in total of a and b. Follow the Hint: line printed beneath the caret underline.
Name Error Referencing a variable or function before defining it, or a spelling typo. Check the suggested Did you mean '...'? hint or initialize with assign.
Type Error Performing math on incompatible types or indexing a non-list. Use type(x) or number(x) to inspect/convert values.
Zero Division Error Dividing or computing remainder by 0. Guard the divisor with if divisor is not 0.
Index Error Accessing a list/string index outside 0..length-1. Check length of list before indexing.
Argument Error Calling a function with too few or too many arguments. Match the parameter count declared in make fn(...).
